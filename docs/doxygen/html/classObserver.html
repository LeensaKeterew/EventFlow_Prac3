Detailed Description

The GoF "Observer" role.

Anything that wants to be told about notices (weather alerts, capacity warnings, and so on) implements this interface. The Subject that is being watched does not need to know what kind of object the Observer really is- it only calls update().

We use "push": the Subject passes everything the Observer needs inside the Notice object, so the Observer never has to call back into the Subject to ask for more information
