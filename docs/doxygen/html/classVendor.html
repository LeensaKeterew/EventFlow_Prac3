Detailed Description

A concrete Leaf: a food/drink vendor.

Like Stage, a Vendor cares whether it is indoors or outdoors, but its role is "serving", not "performing", so its reactions are worded and triggered differently even though the underlying idea is similar- this shows the same rule expressed through independent leaf types rather than a shared "outdoor unit" base class doing the deciding
